## 🏢 About SkyAuctus & Kobra OS

**SkyAuctus** is an advanced local IT and cybersecurity agency operating in Bangladesh, delivering cutting-edge digital infrastructure, application development, and specialized penetration testing solutions. 

**Kobra OS** is our flagship cybersecurity operating system. Built on a robust **Debian** core, Kobra OS combines a stealthy, custom cyberpunk dark glass UI (`~600 MB RAM` idle footprint) with powerful security auditing tools. We eliminate system bloatware to provide ethical hackers and security engineers with a fast, non-intrusive, and battle-ready environment.

---

## ⚡ Core Technical Specifications & Facilities

* **Stealth & Aesthetic:** Custom glassmorphism UI design optimized for low resource consumption.
* **Performance:** Streamlined package architecture designed for high-speed security assessments and rapid updates.
* **Pre-configured Arsenal:** Packed with elite penetration testing and digital forensics utilities.
* **Multi-Architecture Support:** Built for standard `x86_64` systems with future ARM64 device porting in progress.
